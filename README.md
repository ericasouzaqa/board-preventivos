# Painel de Qualidade Preventiva
 
Ferramenta para análise de issues com foco em qualidade preventiva e prevenção de bugs.
 
## O que é
 
Auxilia na análise de issues para identificar riscos e padrões de defeitos antes da entrega.
 
## Como usar
 
1. Importe um arquivo CSV ou XLSX com as issues da sprint
2. Classifique as etiquetas (Preventivo / Incidente / Ignorar)
3. Visualize os indicadores e gráficos gerados
4. Acompanhe análises salvas no histórico
## Formatos aceitos
 
- CSV
- XLSX
## Colunas reconhecidas
 
| Coluna | Obrigatória |
|--------|-------------|
| ID da issue | ✅ Sim |
| Resumo | Não |
| Atribuído | Não |
| Etiquetas | Não |
| Resolvida | Não |
